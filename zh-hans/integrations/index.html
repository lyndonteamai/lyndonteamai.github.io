系统集成

把平台连接到员工已在使用的系统

OpenLMS 建基于 Drupal，意味著集成是第一要务，而不是事后补上的功能。员工数据、身分与学习纪录，通过已设置的数据交换或标准 API 流动。

企业集成

HRIS

保持员工数据一致

通过已设置的数据交换，从现有的人力资源系统接收员工文件、部门、职位数据与在职状况，减少重复输入与过时纪录。

SSO

沿用你现有的企业身分

把平台连接到由机构管理的认证流程，让员工登录更简单，同时由信息科技部掌握身分管控。通过 Drupal 模块支持 SAML 2.0 与 OpenID Connect。

API

把学习信息送到需要的地方

按议定的字段与集成流程，与其他业务系统交换员工、课程、出席、完成与培训纪录数据，经由 REST 或 GraphQL 端点进行。

关于集成的常见问题

实际连接视你的来源系统与双方议定的落地范围。

可集成哪些人力资源系统？

平台支持已设置的人力资源数据交换、单一登录，以及以 API 为基础的数据流程。请带上系统名称、认证要求、字段与更新要求，以便团队确认集成方式。

需要购买商业集成模块吗？

通常不需要。Drupal 提供 SAML、OpenID Connect、JSON:API 与 GraphQL 的社区模块。若特定人力资源系统需要企业连接器，那是一项有范围的工作，而非经常性授权费。

可否迁移我们现有的课程？

可以。LMS Migrate 模块提供由 Opigno 迁移的插件与模板模板。其他系统的 SCORM 套件可直接上载；结构化课程则可用 YAML 套件交换。

告诉我们你需要连接什么

带上你的人力资源系统名称、身分提供者，以及必须维持运行的报表。我们会梳理数据流程。
