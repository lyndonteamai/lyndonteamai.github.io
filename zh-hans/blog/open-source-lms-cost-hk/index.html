开源 LMS 在香港的真正成本

零授权费只是标题。真正的总拥有成本在主机、配置、集成、内容与维运。我们为香港机构诚实地拆解每一条成本线。

重点数据

授权费是多少？
HK$0，没有按人收费，也没有年度续约。
那实际要付什么钱？
主机、配置与客制、集成、内容开发，以及维运与支持。
开源一定更便宜吗？
不一定。对约 40 名员工、培训需求不大的机构，商业授权的总成本可能更低。开源的优势会随学员人数、既有的 Drupal 或 PHP 能力，以及拥有数据的策略价值而增强。
打平点怎样判断？
当同一期内省下的授权成本，大于主机、摊分后的配置、集成、内容、维运工时与升级工作量的总和。
有哪些隐藏成本？
退出成本、升级成本、技能成本、内部开发人力的机会成本，以及 PDPO 下的合规责任。
这篇文章适合谁看？
需要评估 LMS 授权的香港财务与采购团队，以及需要一个诚实总成本数字的 HR 主管。

标题与附带条件

这套说法很有吸引力：企业级学习平台、零授权费、无按人收费、无需年度续约、数据与代码都归你。对一间有 1,200 名学生的香港学区，或一间有 8,000 名员工的企业，这等于拿掉一项本来每年要六位数的开支。

然后采购问题就来了：如果授权是免费的，我们实际付钱买的是什么？这个问题问得对，而开源项目输掉本该赢的生意，往往就是因为答错了这题。

剩下的五条成本线

1. 主机与基建

一个生产环境的 LMS 需要数据库、应用服务器、对象存储、备份与监控。本地机房意味着资本性硬件加上机柜与电费；私有云是月度账单；托管主机也是月度账单，但有人候命。在香港，中型部署的云端支出通常主导整条营运成本。

2. 配置与客制

你不是在安装一个产品，而是在建一个网站。Drupal 提供的是通用 CMS，Drupal LMS 提供的是模块。把它变成你的审批流程、你的报表组合、你的角色结构，是真实工作量。这通常是一次性成本中最大的一项。

3. 集成

每一个必须与 LMS 对话的系统——HRIS、身份供应商、Microsoft 365、Slack、记录培训开支的财务系统——都是一条独立成本线，也带独立风险。集成愈多，总成本愈容易上升，时间表也愈长。

4. 内容

这是多数香港机构低估的一项。授权不会送来教材。H5P 创作是免费但需要设计；SCORM 制作需要创作工具与教学设计；三语内容会把工作量成倍放大。以三年为期，内容成本通常高于平台成本。

5. 维运与支持

总得有人运维：开用户、维护课程、准备报表、平台升级、安全修补。如果这是现有 IT 团队，就是人力成本；如果不是，就是一份托管服务合同。

供应商从不提的成本

隐藏成本实际意味着什么
退出成本专有平台在终止时可能需要数据抽取工作。GPL 平台不需要——但这个价值只有在你真正拥有数据库时才会实现
升级成本商业供应商把大版本升级吸收在订阅内。开源则把这份工作每年、永久地转移给你
技能成本Drupal 与 PHP 是主流技能，某些专有 LMS 技术栈不是。先确认你是要招聘还是要自己培训
机会成本投入平台维护的内部开发人力，其机会成本从来没有人计算
合规成本PDPO、审计证据与保留政策，无论平台由谁运维，都是你的责任

打平点在哪里

一个比较「零授权平台」与「商业按人授权」的粗略模型：

年度授权成本（商业）
  = 授权人数 x 每人费用 x 年数

总拥有成本（开源）
  = 主机
  + 配置（一次性，摊分）
  + 集成（一次性）
  + 内容（持续）
  + 维运工时
  + 升级工作量

打平点：省下的授权成本
大于同一期内所有开源成本线的总和。

令人不舒服的观察是：对一间只有 40 名员工、培训需求不大的小型机构，一旦计入主机与维运，商业授权可能真的更便宜。开源的优势会随学员人数、你本身是否已有 Drupal 或 PHP 能力、以及拥有数据是否具策略价值而增强。

诚实的答案

如果没有任何人向你销售开源平台，要保持怀疑。一间只懂得讲授权经济的供应商，代表没有想过另外五条成本线。

我们会对潜在客户这样说：授权确实免费，而剩下的工作确实要付钱。我们把主机、配置、集成、内容与支持分开报价，也会告诉你什么时候商业平台对你的规模而言是更划算的经济选择。那种对话对我们的价值，远高于一笔我们事后会后悔的生意。

什么时候开源是错的选择

你身边没有人能运维网络平台。你需要合同形式的可用性与问责，而你无法自行交付。你重视「开箱即用」的确定性，多于重视拥有数据。在这些情况下，买商业产品，付钱买确定性。

授权是免费的。但决定仍然应该是对的。

关于开源LMS成本的问题

整体拥有成本里面实际包括什么？

授权费以外有六项：托管与基建、部署与设置、数据与内容迁移、集成与客制开发、内容，以及持续的管理、培训、技术支持与运行。任何没有把这六项分开列出的数字，都不是整体拥有成本，只是穿了外衣的授权费。

打和点在哪里？

视用户人数、你们实际会用到平台多少，以及是否本身已有维运平台的技术能力。对于人数少、培训需求轻的机构，一旦计入托管与管理，商业授权确实可以更便宜。开源的理据在规模扩大、已有Drupal或PHP能力，以及拥有数据本身具策略价值时才最强。

哪些成本最令人意外？

通常是三项：授权费与第一个用户之间那段设置与流程工作；每年重复的管理工时；以及升级工作量——这一项大家常当作零，之后每十八个月就体验一次。它们都不是回避开源的理由，而是把范界定好才对的理由。

迁移成本通常大吗？

视要保留多少历史纪录，以及有多少报表要继续运行，而它经常是开源方案第一年预算里最大的一条。SCORM、H5P或YAML的内容可以原生搬迁；专利内容同旧有报表才是费力所在——所以在任何承诺之前先做一次迁移评估，值得花那点时间。

政府资助计划会改变计算吗？

资助可以改变项目的实际成本，但评估是对具体建议书，不是对产品名称，资格由资助机构决定。我们不会告诉您一定会获批，也不会以资助计划作为购买平台的理由。本网站讨论的每一个计划，都附有它当前的真实状态。

想要一份有诚意的范围报价？

告诉我们你的学员人数、现有系统和需要的报表。我们会在你决定之前逐项列明每一条成本线——如果商业授权对你更便宜，我们也会直接说。
