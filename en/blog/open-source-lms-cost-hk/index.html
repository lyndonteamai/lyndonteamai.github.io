Managed LMS Subscription vs. Cloud Infrastructure Costs

The managed subscription covers platform maintenance and support. Infrastructure is separately billed at cost. Compare vendors using the same users, storage, availability, security responsibilities, and data-export requirements.

Calculate Standard and Scale LMS Subscription Fees

A 100-user Standard subscription is HK$3,000 per year. A 500-user Scale subscription is HK$10,000 per year. Both examples exclude at-cost infrastructure and any agreed installation or custom development.

LMS Setup, Custom Development, and Operating Cost Scope

Self-managed software has no license seat limit. Running it still needs technical administration and infrastructure. On-premises installation covers the agreed standard setup; complex imports, custom connectors, and additional workflows need an agreed development estimate at HK$1,500 per person-day.
