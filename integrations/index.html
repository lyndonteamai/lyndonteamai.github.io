HONG KONG PROJECT PLANNING

Questions your team may ask.

How can an LMS connect with an existing HRIS?

Define identifiers, employee fields, synchronization direction, authentication and permissions. Moodle web services can support scoped interfaces; a working HRIS connector still requires development and testing.

Can Moodle connect to single sign-on?

Moodle offers authentication options that can be configured for an identity environment. Confirm the protocol, plugin compatibility, account linking and access-removal behavior.
