SCORM eLearning for Hong Kong:
Moodle Course Compatibility Guide

Validate existing course packages before committing to a migration.

01

SCORM 1.2 Course Delivery in Moodle Core

Moodle supports SCORM 1.2 delivery. Test package launch, completion, scores and repeat attempts using your actual files.

02

SCORM 2004 Limitations and Integration Evaluation

Native SCORM 2004 support is not available. A commercial player or another evaluated integration may be needed.

03

eLearning Authoring Tools vs. LMS Course Delivery

Moodle delivers SCORM packages; it does not generate SCORM courses. Retain access to source authoring files and licenses.

04

xAPI Learning Records and Separate LRS Integration

xAPI launch and learning record storage require a separately evaluated plugin or integration and LRS architecture.

SCORM Course Compatibility FAQs for Hong Kong Teams

Can Moodle play SCORM 2004 courses?

Moodle does not natively support SCORM 2004. Evaluate an external player or integration and test reporting, licensing and data handling before procurement.

Does Moodle support SCORM 1.2?

Moodle supports SCORM 1.2. Validate your course package, launch behavior, score, completion and repeat attempts in the selected environment.
