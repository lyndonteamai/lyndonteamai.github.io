系統整合

把平台連接到員工已在使用的系統

OpenLMS 建基於 Drupal，意味著整合是第一要務，而不是事後補上的功能。員工數據、身分與學習紀錄，透過已設定的數據交換或標準 API 流動。

企業整合

HRIS

保持員工數據一致

透過已設定的數據交換，從現有的人力資源系統接收員工檔案、部門、職位資料與在職狀況，減少重複輸入與過時紀錄。

SSO

沿用你現有的企業身分

把平台連接到由機構管理的認證流程，讓員工登入更簡單，同時由資訊科技部掌握身分管控。透過 Drupal 模組支援 SAML 2.0 與 OpenID Connect。

API

把學習資訊送到需要的地方

按議定的欄位與整合流程，與其他業務系統交換員工、課程、出席、完成與培訓紀錄資料，經由 REST 或 GraphQL 端點進行。

學習內容整合

把每一個內容庫整合在同一體驗中。

01

SCORM

支援由 Storyline、Captivate 等編寫工具產生的 SCORM 1.2 及 2004 套件。

02

xAPI

匯入 xAPI 套件，並提供精簡 LRS 儲存活動狀態與分數。

03

H5P

開源 H5P 互動活動庫，沒有按活動收費。

04

YAML 套件

以 YAML 檔案的壓縮套件匯出及匯入課程，方便版本控制。

關於整合的常見問題

實際連接視乎你的來源系統與雙方議定的落地範圍。

可整合哪些人力資源系統？

平台支援已設定的人力資源數據交換、單一登入，以及以 API 為基礎的數據流程。請帶上系統名稱、認證要求、欄位與更新要求，以便團隊確認整合方式。

需要購買商業整合模組嗎？

通常不需要。Drupal 提供 SAML、OpenID Connect、JSON:API 與 GraphQL 的社群模組。若特定人力資源系統需要企業連接器，那是一項有範圍的工作，而非經常性授權費。

可否遷移我們現有的課程？

可以。LMS Migrate 模組提供由 Opigno 遷移的插件與範本模板。其他系統的 SCORM 套件可直接上載；結構化課程則可用 YAML 套件交換。

告訴我們你需要連接甚麼

帶上你的人力資源系統名稱、身分提供者，以及必須維持運作的報表。我們會梳理數據流程。
