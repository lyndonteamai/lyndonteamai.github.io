A FEW GOOD QUESTIONS

Hong Kong Moodle LMS: Licensing and Implementation FAQs

Open foundations. Clear expectations.

What is OpenLMS?

OpenLMS is the proposed name for this Moodle-based learning platform offering. This is a marketing website concept, separate from a running Moodle installation.

Is the website built entirely with Astro?

Yes. Every page is statically generated with Astro. The learning platform itself would run on Moodle, separately from this marketing website.

Can we use our existing courses?

Moodle supports course resources, quizzes and SCORM content. Your files, version compatibility and reporting requirements should be checked during migration planning.

Does open source mean everything is free?

Moodle core is open source. Hosting, implementation, support, maintenance, custom development and any paid extensions need a separate agreed scope and quotation.

Can we customize the platform?

Moodle provides themes, plugins and integration interfaces. Requirements, licensing, upgrade compatibility and ongoing ownership should be agreed before development.
